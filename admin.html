MASTER ADMIN CONTROL

Sub-Admin enrollment requests

Review every request. Accept only a name/mobile pair on your authorization whitelist; reject terminates that request.

AUTHORIZED IDENTITIES

Sub-Admin access lifecycle

Control each authorized identity. Hold pauses access; permanent ban blocks re-registration; reset/reactivate clears restrictions and forces fresh password setup; delete removes all records and allows a clean re-add.

RETAIL ID ACTIVATION

Pre-created Retailer profiles

Add the official Retail ID, profile details and registered mobile. The Retailer sets a password once on first login; only a password hash is stored.

DISTRIBUTOR TERRITORIES

PIN code routing

Assign each six-digit service PIN code to one approved Distributor. Matching Retailer applications appear in that Distributor's queue in this browser. Queue links do not authenticate users, and notification delivery is not configured.

SHARED APPLICATION QUEUE

Retailer & Distributor applications

Block permanently prevents future submissions from that mobile. Delete removes only the selected application record. Rejection sends the applicant to the correction and re-upload flow.
